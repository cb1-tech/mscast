# ERP Plan — which document is for whom

## For MSCAST — safe to hand over

| File | What it is | Who at MSCAST |
|---|---|---|
| Data Collection Workbook.xlsx | What MSCAST fills in: masters, balances, people, formats | Accounts and admin |
| Requirements Traceability Matrix.xlsx | Their 97 requirements and how each is met, the 23 additions, and the open questions (answer cells) | Directors |
| Role Cards | One page per job: what you open, do, approve, and what the system refuses | Every staff member |
| SOPs and Use Cases | Each process, step by step | Department heads |
| Operating Recommendations | Rules for correct entries, month-end, system admin | Accounts and the CA |
| Client Setup Guide | Setting the system up for real use | Whoever runs the system, at go-live |

## Internal — for the implementer

| File | What it is |
|---|---|
| Data Request Covering Note | The email to send with the Data Collection Workbook (send the email text, not the file) |
| Demo Run-sheet | Script for the demo meeting (screenshots in `demo-screens/`) |
| Independent Review | Every finding and its status |
| Strategy and Phased Plan · Research Appendix | Why ERPNext, the roadmap, the ERPens comparison, sources |
| Knowledge Base | Research about MSCAST: company, products, market |
| Production Cutover Runbook | Technical steps to move to a real server |
| Implementation Report | One-page summary of what exists |

## Sources

- `markdown/` holds every document as markdown: the editable source, and what the ERP-MSCAST project on claude.ai holds. The Requirements Traceability source (03) is published as the .xlsx workbook only.
- `demo-screens/` holds the screenshots used by the Demo Run-sheet.
